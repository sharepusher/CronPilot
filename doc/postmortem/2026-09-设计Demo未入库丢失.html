设计 Demo HTML 未入库丢失复盘

日期：2026-09-14 · 类型：工程 / 文档

1. Bug 定位

doc/design/任务执行链路可观测性-RunInspector-Demo.html 在会话中曾可读，随后消失；仅残留 .md stub。索引与收敛版设计仍链接该 HTML。git status 显示该文件从未进入 HEAD（始终未跟踪）。

2. 根因

行为层：设计 Demo 先被索引/正文引用，但未入库（未 commit）。工作区一旦发生误删、工具脚注重写或清理，无法用 git checkout 恢复；html_docs_to_markdown.py --check 只校验「已有 HTML→MD 一致」，不校验「索引链接的 HTML 是否仍存在」。

3. 测试漏洞

check_doc_completeness.py 校验「磁盘上每个 HTML 是否登记到 index」，不校验「index 中每个 href 指向的 HTML 是否仍存在」。链接指向已删未跟踪文件时仍可通过登记门禁。

4. 修复

从本轮已读内容重建 任务执行链路可观测性-RunInspector-Demo.html，重新跑 html_docs_to_markdown.py 与 --check；并新增页面对比 Demo，在收敛版设计中补「涉及页面」矩阵。

5. 防护测试

命令：

test -f "doc/design/任务执行链路可观测性-RunInspector-Demo.html" \
  && test -f "doc/design/任务执行链路可观测性-页面对比Demo.html" \
  && .venv-py311/bin/python scripts/html_docs_to_markdown.py --check \
  && .venv-py311/bin/python scripts/check_doc_completeness.py --check

期望：文件存在、MD 同步 OK、登记 OK。

6. 同类排查

git status -- doc/design/：本轮相关 Demo/收敛版多为未跟踪或仅本地修改。历史「对比 Demo」多数已入库；风险主要在待确认设计附属 Demo 长期 untracked。

7. 预防方案

措施落地位置验证
设计稿一旦挂进 doc/index.html 的附属 Demo，须在同轮进入版本库（至少本地 add；用户要求 commit 时一并提交），禁止长期「仅 MD stub + 无 HTML」 AGENTS.md / .cursor/rules/cronpilot-documentation.mdc（设计附属 Demo 入库纪律） git status -- doc/design/*Demo* 不应长期仅有 orphan .md
索引链接存在性：对 doc/index.html 内 href="design/…html" 断言目标文件存在 scripts/check_doc_completeness.py（新增断言；本轮先用手工命令，下轮可编码） python scripts/check_doc_completeness.py --check

本轮可立即验证的手工门禁：

python3 - <<'PY'
from pathlib import Path
import re
root = Path('doc')
html = (root/'index.html').read_text(encoding='utf-8')
missing = []
for href in re.findall(r'href="(design/[^"]+\.html)"', html):
    if not (root/href).exists():
        missing.append(href)
print('MISSING', missing or 'OK')
raise SystemExit(1 if missing else 0)
PY
