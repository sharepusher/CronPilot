版本：v1.4 · 日期：2026-10-13 · 对象：历史图片资产去重与发布包瘦身设计 v1.4 · 评估方式：临时目录全量模拟，未修改仓库图片

1. 结论

以基线 commit 0e1cc411abd60353929065e8618c7193ba077082 为准，模拟完成 H1–H4 后，包含当前已跟踪历史截图的完整 Git source archive 从 28.91 MiB 降至 18.75 MiB。若 19 张待治理 QA 截图经审查后全部入库，完整源码快照预计约 20.67 MiB，另加两份小型引用文档的少量压缩开销。继续按 H5 构建公开安装资产后，不含历史截图的 cronpilot-4.1.0.tar.gz 当前基线预测约 3.09 MiB。历史截图继续保留在 Git 仓库中，不另行生成或发布证据包。

3. 为什么去重后仍有 18.75 MiB

原因不是代码大，而是完整 Git source archive 保留历史证据图片。在 19 张 QA 图纳入统一治理、并删除 5 张无持续证据价值的凭据截图后，现行资产库为 71 张唯一 PNG。PNG 本身已压缩，gzip 对其二次压缩收益很小。v1.4 的 H5 仍在构建公开安装资产时排除全部历史证据图片。

因此，“去重后且仍包含历史截图的完整源码快照”约为 18.75 MiB，而“不携带历史截图的公开安装包”模拟只有约 3.09 MiB。如连非运行时文档也不携带，仅代码、测试和脚本的归档约为 1.20 MiB。

4. “项目大小”的三个口径

  1. 推荐公开安装资产：对 4.1.0 用户安装最有意义的口径是自定义 cronpilot-4.1.0.tar.gz，当前基线预测约 3.09 MiB。
  2. GitHub 自动源码快照：完整包含该 tag 下的仓库文件；只治理当前已跟踪图片时模拟约 18.75 MiB，19 张 QA 图全部入库时预计约 20.67 MiB 加少量文档开销。它是源码快照，不作为轻量安装包口径。
  3. 解压后已跟踪源码大小：只治理当前已跟踪图片时模拟约 27.96 MiB；19 张 QA 图全部入库后约 30.01 MiB，不包含 Git 历史、虚拟环境、数据库和日志。
  4. 完整 clone 大小：在未发现敏感内容的普通治理场景下不重写历史，因此现有 .git 对象不会被删除；完整 clone 不会同比减少 35%。未来提交的 HEAD 和新 tag 会受益，但旧 commit 仍保留历史图片。

5. 模拟方法

  1. 使用 git archive HEAD 在 /private/tmp 生成基线副本，避免将当前未提交变更混入体积差。
  2. 对 doc/ 下 68 个 PNG 计算 SHA-256，以完整哈希命名写入临时 doc/assets/screenshots/。
  3. 解码 30 个 Base64 数据 URI，复用已存在内容，新增 7 张唯一 PNG。
  4. 替换 HTML/Markdown 图片引用，删除旧副本，产生哈希 manifest。
  5. 断言模拟树中数据 URI 为 0、图片引用缺失为 0，再在临时 Git 仓库执行与基线同格式的 git archive --format=tar.gz。

6. 19 张新 QA 截图的影响

doc/qa/assets/ui-compare-2026-09/ 当前共 19 张、2,153,774 字节（约 2.05 MiB），全部哈希唯一，且与现有 68 张文档 PNG 无重合；独立 gzip 归档为 2,015,282 字节（约 1.92 MiB）。它们尚未跟踪，因此不在上述 18.75 MiB 中。若经公开内容安全与来源审查后全部入库，完整源码快照预计由 18.75 MiB 增至约 20.67 MiB；公开安装包不受影响。

7. 准确性边界

  • 10.16 MiB 是图片治理的隔离实测收益，可用作实施后的对照基准。
  • 18.75 MiB 不是最终 4.1.0 源码快照大小承诺，因为它不含 19 张待治理 QA 图，也不含其他待提交代码和核心文档变更。最终 tag 应重新执行同一命令并报告实际字节数。
  • 3.09 MiB 是当前基线下排除历史截图后的预测值，不是未来代码冻结后的绝对上限。H5 必须报告最终实测值，并逐项说明由已批准 4.1.0 核心变更带来的增量；历史截图贡献必须为 0。
  • 该 3.09 MiB 模拟尚未证明白名单包可独立安装，也未验证入口文档链接闭包；这两项必须由 v1.4 的 H5 在最终 tag 上完成后，才能形成正式发布结论。

8. 专业意见

图片去重仍然值得实施，但它只解决“重复存储”，不解决“历史证据是否应进入发布产物”。4.1.0 应保持通过公开审查的截图在源码仓库中可审计，但将 doc/assets/screenshots/ 及仅依赖这些截图的非核心材料从公开安装资产中排除。推荐发布包当前基线预测约 3.09 MiB；最终值以 tag 白名单构建、链接闭包和解压安装验收为准。
