OPT-P0-22 同名停用覆盖启用 — 前端页面对比 Demo

rev.3 · 左侧 Before / 右侧 After · 黄框为变更焦点

关联：停用用户同名恢复设计.html · 须用浏览器打开

产品原则（rev.3） 同名再申请未必是原使用人。申请人侧零提示。仅审批人与管理员需知情：将覆盖旧停用账号的资料与权限；因同一 user_id，历史日志会被继承。
对比清单
  1. 注册页（申请人）— 无同名提示
  2. 用户管理 · 停用确认弹窗
  3. 停用用户独立页
  4. 编辑用户 · 状态文案
  5. 注册审批 · 列表 + 批准弹窗（审批人）
  6. 添加用户 · 同名确认弹窗（管理员）

0. 注册页（申请人）

register.html 申请人 · 零提示

即使邮箱前缀对应用户名与已停用账号相同，注册页也与普通新注册完全一致，不出现「曾被停用 / 恢复 / 覆盖」等任何提示。
