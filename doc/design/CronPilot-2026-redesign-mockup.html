API 文档

CronPilot REST API 参考
GET /api/cron/list 获取任务列表
POST /api/cron/add 创建定时任务
POST /api/cron/edit 修改定时任务
POST /api/cron/run 立即执行任务
POST /api/cron/add_log 回传执行进度
GET /api/cron/status 查询任务状态
GET /api/cron/log_list 获取执行记录列表
Parameters
cron_id integer, required — 任务 ID
page integer, optional — 页码，默认 1
per_page integer, optional — 每页条数，默认 20
Response Example
{ "errcode": 0, "data": { "list": [...], "total": 42 } }
