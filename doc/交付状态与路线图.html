六、文档维护约定

  • 每次发布版本：更新 RELEASE_NOTES.md、本页「按版本汇总」、相关设计稿页眉状态；将 [Unreleased] 中已交付条目下沉到对应版本节。
  • 每项新优化：先设计稿（§待确认）→ 实现 → 验收 → 本页标「已交付」+ 版本号 → Release Notes。
  • 下一版待交付：在 Release Notes [Unreleased] 维护草稿条目，与本页「建议实施顺序」及设计稿链接对齐；勿用「Unreleased」指已发布内容。
