# 全量测试与 Bugbot 复核（2026-09）

**日期：**2026-09-14　**状态：**已通过全量验证

## 1. Bug 定位

首次全量测试执行 754 项，4 failures、1 error、11 skipped。Bugbot 发现 B1 的 last-admin 负向用例被改成正向断言，保护失去覆盖。

## 2. 根因

测试类 fixture 预先创建了 `ops_admin`，因此 `solo` 并非最后一个管理员；测试为适配当前数据而放宽断言，掩盖了原始安全契约。

## 3. 测试漏洞

用例未显式保证数据库中只有一个启用 admin，导致名称与场景语义脱节。

## 4. 修复方案

恢复真正单管理员 fixture，并断言停用被拒绝；另增非最后管理员可编辑用例。全量失败中的 API DNS、迁移主键、ORM legacy guard 分别列入 B2 修复。

## 5. 防护测试

运行 `.venv-py311/bin/python -m unittest tests.test_rbac_phase -v`，再运行全量 discover；目标为 0 failure、0 error。

## 6. 同类排查

检查所有 RBAC 管理员 fixture 是否显式控制 admin 数量，并核对每个安全否定断言确实覆盖拒绝分支。

## 7. 预防方案

新增测试辅助断言，验证“last-admin”场景中启用 admin 计数恰为 1；位置：`tests/test_rbac_phase.py`，由 CI 定向执行并在 Bugbot 复核前运行。

## 证据

最终全量日志：`/private/tmp/cronpilot-full-final2.log`，754 项结果 **OK（skipped=11）**；Bugbot 定位：`tests/test_rbac_phase.py:713`。

已恢复真正的 last-admin negative case，补齐离线 DNS 与迁移主键夹具，并修正 ORM legacy guard 对 `urlsplit(...).query` 的误报。
