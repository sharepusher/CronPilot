## 待处理偏离项（按优先级）

高

C1: 用户管理列数 5→9（花名/岗位/业务组/密码状态超出 Mockup）

Mockup 设计 5 列精简表。当前 9 列在 1440px 视口已引发过布局问题（已修复水平滚动），但列数多导致信息过密。需讨论是否精简或保持当前富信息结构。

中

C2: 审计日志列顺序与 Mockup 不同（时间/事件对调）

Mockup：事件→用户→时间→IP→结果。当前：时间→用户名→动作→详情→来源IP。"时间"前置和增加"详情"列是已有设计决策，可能需确认是否对齐或维持。

中

C3: 操作记录缺少来源 IP 列，多出变更详情列

Mockup 操作记录有"来源 IP"列。当前实现将 IP 移到审计日志，增加了"变更详情"列。需确认这是已确定的职责分离设计，还是需要在操作记录也显示 IP。

低

C4: 标签管理新建交互方式（内联 input vs 独立按钮）

Mockup 用搜索式 input 框（占位符"+ 新建标签…"）内联创建。当前用独立按钮+弹框。功能等价，视觉差异轻微。

低

C5: 角色 Badge 文案（中文 vs 英文）

Mockup 用中文标签（管理员/运维/观察者）。当前用英文（admin/operator/viewer）。可能影响非技术用户的可读性。
