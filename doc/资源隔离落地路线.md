## 二、阶段门禁（摘要）

### S1–S2

全 GLOBAL 时行为与 RBAC v4 一致；纯函数单测绿。

### S3

他组直接 URL → 403；列表不可见；admin 全可见。

### S4

`js-ajax-form`+`js-ajax-submit`；建组→绑用户→GROUP 任务隔离可走通。

### S5

`bash scripts/cronpilot.sh test`（含 `tests.test_rbac_scope`）；文档 HTML↔MD `--check`。

## 三、PR 切分建议

| PR | 内容 |
| --- | --- |
| A | S0 文档 |
| B | S1+S2 Schema+核心 |
| C | S3 接线（隔离生效） |
| D | S4 UI |
| E | S5 发布文档 |

本仓库可将 A–E 合并为同一交付轮；最小安全增量 = Schema + authorize + views 接线。

## 四、明确不做（S0–S5）

- 第四角色 / Role↔Group
- `/api/*` 按组隔离
- 删除业务组
- Resource Policy 业务规则
- `cron_service` 内角色/组判断
