1. Bug 定位

R3-C 短设计的 #page-compare 多次自造变体（点列+标签、保留 HTTP、五行注释）， 与权威源 doc/design/任务执行链路可观测性-页面对比Demo.html §B 的 AS-IS / TO-BE 画面不一致。用户要求：「改造后页面 demo 应该和上面文档的一致」。

2. 根因

行为层：写子设计时未把 Demo §B 的 HTML 逐行抄进 AFTER，而是「语义对齐 + 现网列保留」自行折中 （先拼圆点+标签，再保留 HTTP）。门禁只查有无 page-compare，不强制与父 Demo 列数/样例行同构。

3. 测试漏洞

grep page-compare|BEFORE|AFTER 与「含 ● 超时」对「Demo+HTTP」变体仍绿。 无「AFTER 列数 / 样例行 = 父 Demo TO-BE」机械对照。

4. 修复

  • rev.3：R3-C #page-compare 原文照录 Demo §B 的 AS-IS / TO-BE（标题、三行、文案、变化说明相同）。
  • 删掉自造 BEFORE（空白时间/HTTP/行注）、纠偏说明与折中列讨论；方案节只指向该对照。
