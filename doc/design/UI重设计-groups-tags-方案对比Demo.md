## 实施计划汇总

基于以上对比，推荐组合方案：Groups M2 + Tags T2

| 页面 | 推荐方案 | 需改动文件 | 估计复杂度 | 验收方式 |
| --- | --- | --- | --- | --- |
| **groups.html** | M2 增强卡片 | `app/rbac/views.py`（groups\_list 增加 2 查询）  `app/templates/redesign/groups.html` | 小（~40 行 view + 模板重写） | 浏览器截图对比 Mockup 卡片 |
| **tags.html** | T2 上云下表 | `app/templates/redesign/tags.html`（仅模板） | 小（新增云区块 + 简化表格） | 浏览器截图，云区块 + 表格均可见 |

**验收命令序列：**  
1. `bash scripts/cronpilot.sh restart --daemon`  
2. `curl -s http://127.0.0.1:5001/rbac/login -w "%{http_code}"` → 确认 200  
3. 登录管理员账号 → 访问 `/rbac/groups`（卡片网格）→ 访问 `/rbac/tags`（上云下表）  
4. `python -m unittest tests.test_redesign_sidebar -v` → 12 个用例全通过
