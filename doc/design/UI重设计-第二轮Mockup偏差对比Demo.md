## 执行记录：LOG ID 列 + 完整返回内容 vs 简洁响应码（功能型偏差）

★ 低

现状（LOG ID + 完整返回内容）

| LOG ID | 任务名称 | 返回内容 | 执行时间 | 耗时 | 结果 | 操作 |
| --- | --- | --- | --- | --- | --- | --- |
| 11980 | admin-multi-group-task | HTTP 404 · HTML Response (559 bytes) | 2026-08-19 10:10:00 | 399ms | 失败 | 详情 |

当前 7 列；完整返回内容文字占空间大；LOG ID 列对一般用户价值低

Mockup 标准（简洁 5 列）

| 任务 | 触发时间 | 耗时 | 响应码 | 状态 |
| --- | --- | --- | --- | --- |
| admin-multi-group-task | 2026-08-19 10:10 | 399ms | 404 | 失败 |

建议

保留 LOG ID 但缩窄；"返回内容"截断为 HTTP 状态码 + bytes 标记（已接近 Mockup 响应码列）
