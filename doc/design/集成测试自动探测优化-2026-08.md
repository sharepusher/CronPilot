# 集成测试自动探测优化

状态：已实施 · 2026-08-28

---

## 1. 问题

项目有 11 个集成测试（`test_csrf_integration.py`），通过 `requests.Session` 对运行中的 CronPilot 服务发送真实 HTTP 请求，验证 CSRF 全链路和权限拦截。

当前行为：这些测试需要手动设置 `CRONPILOT_BASE_URL=http://127.0.0.1:5001` 环境变量才会执行。`cronpilot.sh test` 和 CI 中均不设置此变量，因此 **11 个测试永远被跳过**。

用户反馈：本地服务明明已在 5001 端口运行，但测试仍显示 `skipped=11`，不够直观。

## 2. 根因

集成测试设计为"opt-in"模式——因为测试会发送 POST 请求（创建任务、切换状态等），有数据库副作用，所以不敢默认执行。但实际上这些测试使用种子 `admin/changeme` 账号，操作的是测试任务，且在每次 `setUpClass` 中重新登录，副作用可控。

缺少自动探测机制：测试不会检查本地端口是否有服务在监听。

## 3. 方案

在 `test_csrf_integration.py` 的模块级初始化中增加自动探测逻辑：

1. 如果 `CRONPILOT_BASE_URL` 已设置，沿用现有行为（连接该地址）
2. 如果 `SKIP_INTEGRATION=1`，强制跳过（CI 可用此开关）
3. 如果两者均未设置，尝试连接 `http://127.0.0.1:5001/rbac/login`（本地），若不通再尝试 `:5860`（Docker）
4. 如果两个端口都不通，正常跳过并提示原因

优先级：`SKIP_INTEGRATION=1` > `CRONPILOT_BASE_URL` > 自动探测 :5001 > 自动探测 :5860 > 跳过

### 代码变更

```
# test_csrf_integration.py 模块级变量初始化
BASE_URL = os.environ.get('CRONPILOT_BASE_URL', '').rstrip('/')
_SKIP_REASON = None

if os.environ.get('SKIP_INTEGRATION', '').lower() in ('1', 'true', 'yes'):
    _SKIP_REASON = 'SKIP_INTEGRATION=1; skipping integration tests'
elif not BASE_URL:
    import requests as _req
    for _port in (5001, 5860):
        try:
            _req.get('http://127.0.0.1:%d/rbac/login' % _port, timeout=2)
            BASE_URL = 'http://127.0.0.1:%d' % _port
            break
        except Exception:
            pass
    if not BASE_URL:
        _SKIP_REASON = 'No CronPilot service on :5001 or :5860; set CRONPILOT_BASE_URL or start the service'
else:
    try:
        import requests as _req
        _req.get(BASE_URL + '/rbac/login', timeout=3)
    except Exception as e:
        _SKIP_REASON = 'Service at %s unreachable: %s' % (BASE_URL, e)
```

## 4. 范围

- 修改：`tests/test_csrf_integration.py` 和 `tests/test_cron_ops_integration.py`（两个集成测试文件的模块级初始化逻辑）
- **不改**：测试用例本身、CI workflow、`cronpilot.sh`

## 5. 分批

单文件单批次，改完即可验收。

## 6. 验收

| 场景 | 预期 |
| --- | --- |
| 服务运行 + 无环境变量 | 11 个测试自动执行（不再 skipped） |
| 服务未运行 + 无环境变量 | 11 个测试跳过，提示 `No CronPilot service on :5001 or :5860` |
| `SKIP_INTEGRATION=1` | 无论服务是否运行，均跳过 |
| `CRONPILOT_BASE_URL=...` | 使用指定 URL（现有行为不变） |

## 7. 风险

- **自动探测增加测试启动时间**：探测超时设为 2 秒，最多尝试 2 个端口 = 最差 4 秒。当服务运行时首次探测即成功，增加 <0.5 秒。
- **CI 误触发**：CI 无本地服务监听，探测自然失败，行为与现在一致（跳过）。如需显式保障，可在 CI workflow 中加 `SKIP_INTEGRATION=1`。
- **POST 副作用**：现有测试通过种子 admin 账号操作，副作用可控。但建议长期将集成测试数据隔离到专用测试任务/用户。
