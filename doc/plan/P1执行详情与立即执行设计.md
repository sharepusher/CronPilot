## 一、背景

| 已有（909fd24 及以前） | 仍缺 |
| --- | --- |
| `/job_log_detail?id=` 弹窗（iframe）展示 HTTP 全文 + P1 徽章  任务列表仅有「运行记录」iframe、运行/停止、编辑、删除 | **无法分享**某次执行固定链接（iframe URL 难收藏）  **无法一键补跑**，联调只能改 cron 或调 API  详情页无顶栏导航，不像独立「Run 页」 |

## 二、方案总览

| 项 | 推荐 | 说明 |
| --- | --- | --- |
| **P1-03** | **方案 D1** | 独立整页 `/job_log/<id>`，保留 iframe 作快捷方式 |

## 三、P1-03 · 执行详情页（方案 D1）

### 3.1 路由

| 路由 | 行为 |
| --- | --- |
| `GET /job_log/<int:job_log_id>` | **主入口**：完整管理端布局（顶栏 tabs + 内容区） |
| `GET /job_log_detail?id=` | **保留**：无导航的轻量页，供 iframe；内部可复用同一 partial |

分享链接示例：`http://host:5860/job_log/147`（需登录 Session，不新增公开 token）。

整页详情 D1（推荐）

### 3.3 列表入口调整

| 位置 | 现行为 | D1 后 |
| --- | --- | --- |
| 执行记录「查看详情」 | iframe 弹窗 | **默认**新开整页 `/job_log/<id>`；旁链「弹窗查看」可选保留 |
| 任务内「运行记录」 | iframe `job_log_list` | 记录行「查看详情」同样链到 `/job_log/<id>` |

**推荐（简化）：**「查看详情」统一改为整页跳转，**去掉 iframe**，减少双套 UX。若你需保留弹窗，确认后加「小窗」链接。

## 四、P1-04 · 立即执行（方案 R1）

### 4.1 交互

任务列表 · 操作列（推荐）

| 任务 | 操作 |
| --- | --- |
| teststp（运行中） | [立即执行](#) · [运行记录](#) · [停止](#) · 编辑 · 下线 |

- 点击「立即执行」→ 确认框（可选，默认**要**）→ POST → 等待（回调最长 120s）→ 跳转 `/job_log/<new_id>`
- **不校验**任务 `status==1`：已暂停任务也可手动跑一次（仅读 `cron_infos` + URL）；已下线（`status=-1`）不可
- 若 `req_url` 为空 → 返回 JSON 错误，不调用 `cron_do`

### 4.2 后端流程

POST /cron\_run\_now?id=<cron\_id> (@login\_required)
→ 校验 CronInfos 存在、req\_url 合法
→ 调用 run\_cron\_now(cron\_id) # 包装 cron\_do，返回 job\_log.id
└─ 仍走 @single\_task：集群 120s 内同任务互斥；冲突时返回「执行中，请稍后」
→ web\_api\_return(code=0, url='/job\_log/%s' % job\_log\_id)

### 4.3 `cron_do` 改造（最小）

| 项 | 说明 |
| --- | --- |
| 返回值 | `cron_do` 成功时返回 `job_log.id`（int），失败/跳过返回 `None` |
| 调度触发 | APScheduler 调用处忽略返回值（行为不变） |
| `single_task` 冲突 | 返回 `None` → 立即执行接口 `code=1, msg=任务正在执行中` |

## 五、方案对比（未采纳）

**P1-03 仅 iframe 优化**

不换路由，只放大弹窗。仍无法分享、无浏览器历史。

**P1-04 后台异步**

提交后先跳列表轮询。复杂度高，留 P2/SSE 一并做。

## 六、实现触点

| 文件 | 变更 |
| --- | --- |
| `app/crons.py` | `cron_do` 返回 `job_log.id`；`_save_job_log` return jl |
| `app/main/views.py` | `job_log_show` 整页路由；`cron_run_now` POST |
| `app/templates/job_log_show.html` | 整页详情（含 tabs） |
| `app/templates/_job_log_detail_body.html` | 详情正文 partial（整页与 iframe 共用） |
| `cron_list.html` | 操作列加「立即执行」 |
| `job_log_*_list.html` | 「查看详情」链到 `/job_log/<id>` |

## 七、验收清单

1. 执行记录点「查看详情」→ 整页 URL 为 `/job_log/<id>`，刷新仍可用
2. 详情含：P1 徽章、HTTP、fail\_reason、content、关联任务名与 cron 表达式
3. 任务列表「立即执行」→ 完成后自动打开**本次**详情页
4. 120s 内重复点立即执行 / 与定时触发重叠 → 提示忙，不双写错乱
5. 无 `req_url` 任务 → 立即执行失败提示
6. `bash scripts/cronpilot.sh test` + Docker 冒烟
