任务中心 (dashboard.html)

PARTIAL

Mockup 规格 (view-dashboard)

  • 7列表格：任务/调度策略/健康度/最近执行/下次执行/业务组/操作
  • Stats: 4 卡片（异常任务/连续失败/运行中/今日失败次数）
  • Exception Panel（需要关注的任务）
  • Chip 筛选器 + 数量徽章（全部128/异常3/运行中6/暂停12/已下线4）
  • 行内 icon-only 操作：立即执行/暂停/更多
  • 页头右上角"新建任务"按钮

当前实现

  • ✅ 7列表格正确（任务/调度策略/健康度/最近执行/下次执行/业务组/操作）
  • ✅ 4个Stats卡片匹配Mockup标签
  • ✅ Exception Panel（需要关注的任务 5 条）
  • ❌ 筛选器改为按钮组+下拉框，无数量徽章，无"已下线"chip
  • ❌ 操作列：立即执行icon + 执行记录icon + 更多下拉（与mockup不同）
  • ❌ 新建任务在筛选栏，非页头右上角
D2 🟡
新建任务 CTA 位置
Mockup: 页头右上角 btn-primary 实际: stat-line 内行内链接
D3 🟡
筛选栏结构不符
Mockup: chip 筛选器（含数量徽章，5种状态） 实际: 按钮组 + 下拉框，无计数徽章，无"已下线"
D5 🟡
行操作按钮
Mockup: 3 个 inline icon（立即执行/暂停/更多） 实际: 执行icon + 执行记录icon + 更多下拉

执行记录 (execution_logs.html)

FAIL 🔴

Mockup 规格 (view-logs)

  • 7列：任务 / 触发时间 / 耗时 / 响应码 / 状态 / 失败原因 / (icon操作)
  • Chip 筛选器：全部/失败/超时 + 业务组▾
  • 状态列：health badge（绿/红）
  • 操作：icon-only eye 图标（查看详情）
  • 失败行背景高亮（danger-bg）

当前实现

  • 7列（数量相同但内容完全不同）：LOG ID / 任务名称 / 返回内容 / 执行时间 / 耗时 / 结果 / 操作
  • ❌ 缺少：响应码、失败原因 独立列
  • ❌ 筛选器：结果状态按钮组 + 日期范围（非chip）
  • ❌ 操作：文字按钮"详情"（非icon-only）
  • ⚠️ 失败行左边框高亮（与Mockup 背景高亮不同）
D1 🔴
表格列名完全不符（7列但内容差异显著）
Mockup: 任务|触发时间|耗时|响应码|状态|失败原因|icon 实际: LOG ID|任务名称|返回内容|执行时间|耗时|结果|详情
D2 🔴
缺少 响应码 和 失败原因 独立列
Mockup: 独立的 响应码(HTTP status) 和 失败原因 列 实际: 合并到 返回内容/结果 中，无法按字段筛选
D3 🟡
筛选器结构不符
Mockup: chip(全部/失败/超时) + 业务组▾ 实际: 状态按钮组(5种) + 任务名/内容搜索 + 日期范围
D4 🟡
操作列按钮类型
Mockup: icon-only 眼睛图标 实际: 文字按钮"详情"

FAIL 🔴

Mockup 无表格，实际是表格为主
Mockup: 零表格，只有 namespace pill 实际: c-table（5列）是主体 UI
