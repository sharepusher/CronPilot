日期：2026-09-16 · 类型：文档 / 设计交付 · rev.2（规范升级为「凡前端页面可见改动」）

1. Bug 定位

「任务中心排除已下线」方案写在 doc/design/任务中心排除已下线任务统计与默认列表设计-2026-09.html， 页面对比却单独落在 doc/design/任务中心排除已下线-页面对比Demo.html。 Review 时需在两份文档间跳转，方案与画面不同步。

2. 根因

行为层：用户要求「方案里应有页面对比」时，Agent 套用仓库内多页 / 大入口改造的独立 Demo 惯例 （如用户管理入口、执行链路多页对比），而未区分本轮是单页 UX 文案/筛选语义变更。 同仓库内「逾期未执行」「筛选按钮视觉」等设计已采用正文内嵌 Before/After，却未被选为默认模板。

3. 测试漏洞

文档门禁只校验 HTML↔MD、索引登记与链接可达，不校验「单页 UX 设计是否自带内嵌对比」。 拆成两份且互相链接时，门禁仍全绿。

4. 修复

  • 将完整 Before/After 并入设计稿 §3.1.1（rev.4）。
  • 删除独立 Demo HTML/MD，避免双源。
  • 索引改为只指向设计稿（注明「内嵌页面对比」）。
