# UX 设计方案与页面对比拆分复盘

**日期**：2026-09-16 · **类型**：文档 / 设计交付 · **rev.2**（规范升级为「凡前端页面可见改动」）

## 1. Bug 定位

「任务中心排除已下线」方案写在
`doc/design/任务中心排除已下线任务统计与默认列表设计-2026-09.html`，
页面对比却单独落在
`doc/design/任务中心排除已下线-页面对比Demo.html`。
Review 时需在两份文档间跳转，方案与画面不同步。

## 2. 根因

行为层：用户要求「方案里应有页面对比」时，Agent 套用仓库内**多页 / 大入口改造**的独立 Demo 惯例
（如用户管理入口、执行链路多页对比），而未区分本轮是**单页 UX 文案/筛选语义**变更。
同仓库内「逾期未执行」「筛选按钮视觉」等设计已采用正文内嵌 Before/After，却未被选为默认模板。

## 3. 测试漏洞

文档门禁只校验 HTML↔MD、索引登记与链接可达，不校验「单页 UX 设计是否自带内嵌对比」。
拆成两份且互相链接时，门禁仍全绿。

## 4. 修复

- 将完整 Before/After 并入设计稿 **§3.1.1**（rev.4）。
- 删除独立 Demo HTML/MD，避免双源。
- 索引改为只指向设计稿（注明「内嵌页面对比」）。

## 5. 防护测试

```

python3 scripts/html_docs_to_markdown.py --check
```

期望：独立 Demo 不存在；设计稿含锚点与 After 画面；MD 同步 OK。

## 6. 同类排查

| 文档 | 形态 | 结论 |
| --- | --- | --- |
| 任务中心逾期未执行 / 筛选按钮视觉 | 正文内嵌 vs | 正确模板，本轮应对齐 |
| 用户管理入口 / 停用恢复 / 执行链路多页 | 独立 Demo | 多页或大入口，保留独立 Demo 合理 |
| 本轮「排除已下线」 | 曾拆分 → 已合并 | 单页 UX，应内嵌 |

## 7. 预防方案

**rev.1**：在 `cronpilot-documentation.mdc` / `AGENTS.md` 追加「单页 UX 对比默认内嵌」。

**rev.2（2026-09-16 · 用户明确要求）**：升级为总则
**「前端页面对比 Demo」**——凡模板 / Redesign CSS / 导航 / 筛选 / 统计 / badge / 表单布局等**可见改动**，
设计稿必须含 Before/After；缺对比 = 设计不完整，不得请确认开干。

- `.cursor/rules/cronpilot-project.mdc`（设计必备 + UI 确认表「页面对比」行）

- `AGENTS.md` 协作闭环
