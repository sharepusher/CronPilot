## 六、文档维护约定

- 每次**发布版本**：更新 [RELEASE\_NOTES.md](../RELEASE_NOTES.md)、本页「按版本汇总」、相关设计稿页眉状态；将 `[Unreleased]` 中已交付条目下沉到对应版本节。
- 每项**新优化 / 功能**：先出**清晰完整准确**的设计稿（须含**分批**与**验收**）→ **经确认** → 再实现 → 验收 → **可验证本地环境**（restart + URL/登录/步骤/断言 + Agent 自证；默认保持服务运行）→ 本页标「已交付」+ 版本号 → Release Notes。**确认前不写实现代码**；「请完成 XX」不等于设计已确认。详仓库 `.cursor/rules/cronpilot-project.mdc`「设计先行」「交付后可验证本地环境」。
- **下一版待交付**：在 [Release Notes [Unreleased]](RELEASE_NOTES.html) 维护草稿条目，与本页「建议实施顺序」及设计稿链接对齐；勿用「Unreleased」指**已发布**内容。
