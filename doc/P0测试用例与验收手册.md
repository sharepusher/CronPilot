### 测试环境基线

- **Python**：3.8～3.11（与 Flask 1.1 / Werkzeug 1.0 兼容；勿用 3.12+ 跑完整应用）
- **配置**：项目根目录 `conf.ini`（已在 .gitignore，勿提交）
- **启动**：`bash scripts/start_local.sh` 或见下文「本地启动」
- **管理端**：`http://127.0.0.1:5001/` · 密码见 `conf.ini` 的 `login_pwd`
- **自动化**：`python -m unittest tests.test_p0_phase_a -v`（12 用例，无需 DB）

## 详细用例

### OPT-P0-01 · SQL 参数化

|  |  |  |  |
| --- | --- | --- | --- |
| TC-P0-01-01 | 删除定时任务时关联 job\_log 被清除 | | |
| 前置 | 已登录；存在任务 A 且至少有 1 条执行记录 | | |
| 步骤 | 任务列表 → 删除任务 A → 查看该任务执行记录列表 | | |
| 预期 | 任务消失；对应 `job_log` 无残留；无 SQL 报错 | | |
| 实现 | `JobLog.query.filter(...).delete()`（`job_log_service`） | | |

|  |  |  |  |
| --- | --- | --- | --- |
| TC-P0-01-02 | 日志超限清理使用 ORM | | |
| 步骤 | 将某任务执行记录增至 > `job_log_counts`，等待 `cron_del_job_log` 或手动触发 | | |
| 预期 | 仅保留最近 N 条；代码中无 `execute("%` 拼接 | | |

### OPT-P0-02 · 密码哈希

|  |  |
| --- | --- |
| TC-P0-02-01 | 明文 `login_pwd=123456` 可登录 |
| TC-P0-02-02 | 执行 `python scripts/hash_login_password.py 你的密码` 后，仅哈希可登录 |
| TC-P0-02-03 | POST `/check_pass` 正确密码 → 302 到 `/cron_list` |
| 注意 | 修改 `conf.ini` 后**必须重启**进程（`LOGIN_PWD` 在启动时加载） |

### OPT-P0-03 · SSRF 防护

|  |  |  |  |
| --- | --- | --- | --- |
| TC-P0-03-04 | Web 添加任务 `req_url=http://127.0.0.1/x` | | |
| 预期 | JSON `errcode:1`，msg 含「不允许回调本机」 | | |
| TC-P0-03-03 | `url_allow_hosts=8.8.8.8` 时仅允许该主机 | | |
| TC-P0-03-05 | 若绕过保存（历史数据），触发执行后 job\_log 记录「安全校验未通过」 | | |

## 手工 curl 脚本（可复制）

```
BASE=http://127.0.0.1:5001
COOKIE=/tmp/xnc_cookie.txt

# 登录（密码与 conf.ini 一致）
curl -s -c "$COOKIE" -b "$COOKIE" -X POST "$BASE/check_pass" \
  -d "password=123456" -L -o /dev/null -w "login %{http_code}\n"

# SSRF 应失败
curl -s -b "$COOKIE" -X POST "$BASE/cron_add" \
  -d "task_name=ssrf_test" -d "hour=9" -d "minute=0" \
  -d "req_url=http://127.0.0.1/cb" -d "ds_ms=2"

# 合法添加
curl -s -b "$COOKIE" -X POST "$BASE/cron_add" \
  -d "task_name=ok_test" -d "hour=10" -d "minute=0" \
  -d "req_url=http://8.8.8.8/cb" -d "ds_ms=2"

# API
curl -s -X POST "$BASE/api/cron" \
  -d "task_name=ok_test" -d "hour=11" \
  -d "req_url=http://8.8.8.8/cb2"
```
