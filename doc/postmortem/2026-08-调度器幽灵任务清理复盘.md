# 复盘：调度器幽灵任务（OPT-P0-20）

**日期**：2026-08-26   **关联设计**：`doc/design/调度器幽灵任务清理设计.html`

## 1. Bug 定位

- **Bug 1**：`app/services/cron_service.py` `retire_cron_by_id()` / `retire_cron_by_task_name()` 中 `remove_job()` 异常被静默吞掉（`except Exception: _log.warning(...)`），但 `apply_retire` + `db.session.commit()` 仍执行，导致数据库已退休但调度器未清理
- **Bug 2**：`app/crons.py` `cron_check()` 只检查正向孤儿（活跃任务不在调度器），`if item.status == -1: continue` 主动跳过退休任务，不检查反向孤儿（已退休但仍在调度器）

## 2. 根因

- **Bug 1**：操作顺序设计不当——先持久化状态变更（`apply_retire`），再执行调度器操作（`remove_job`），异常发生时两库不一致。应先完成调度器操作再持久化
- **Bug 2**：OPT-P0-18 安全加固时只关注了正向方向，未考虑反向。`cron_check` 的跳过逻辑使幽灵任务成为永久监控盲区。每次重启 `scheduler.start()` 重新加载幽灵任务，形成永久不一致

## 3. 测试漏洞

- `test_rbac_phase.py` 和 `test_operation_log.py` 中 `remove_job.side_effect = Exception('no job')` 模拟调度器失败，但断言假定退休仍成功——恰好掩盖了 Bug 1
- 无测试覆盖 `cron_check()` 的反向扫描行为

## 4. 修复

| Bug | 修复 | 文件 |
| --- | --- | --- |
| Bug 1 | 调整执行顺序为"先 remove\_job → 后 apply\_retire + commit"；`JobLookupError` 幂等放行；其他异常中止退休操作返回错误 | `app/services/cron_service.py` |
| Bug 2 | `cron_check()` 增加反向扫描：`status=-1` 的幽灵任务自动 `remove_job`；`cron_infos` 无记录的残留仅告警不清理 | `app/crons.py` |
| 测试适配 | `side_effect = Exception` → `side_effect = JobLookupError` | `tests/test_rbac_phase.py`, `tests/test_operation_log.py` |

## 5. 防护测试

`tests/test_ghost_job_cleanup.py`（10 个用例）：

- `TestRetireFlowHardened`：3 个用例 — 正常退休 / `JobLookupError` 幂等 / 其他异常中止
- `TestRetireByTaskNameHardened`：3 个用例 — 对称覆盖 API 退休入口
- `TestCronCheckReverseScan`：4 个用例 — 幽灵清理 / 残留仅告警 / 活跃不误伤 / 暂停不误伤

```
python -m unittest tests.test_ghost_job_cleanup -v
```

## 6. 同类排查

- `CuGeventScheduler.py` / `CuBackgroundScheduler.py` 的 `update_cron_info()` 也调用 `apply_retire()`，但紧接 `self.remove_job()` 在同一循环中执行，无时序问题
- `register_cron_job()` 的 `try: scheduler.remove_job(...) except: pass` 是添加前幂等清理，不涉及状态一致性

## 7. 预防方案

| 措施 | 落地位置 | 验证命令 |
| --- | --- | --- |
| 反向扫描随 `cron_check()` 每轮自动执行 | `app/crons.py` | `grep "ghost\|stale" datas/logs/local-server.log` |
| `cronpilot_ghost_tasks` Prometheus gauge | `app/metrics.py` | 服务运行后查 `/metrics` 端点 |
| 10 个单元测试覆盖退休流程和反向扫描 | `tests/test_ghost_job_cleanup.py` | `python -m unittest tests.test_ghost_job_cleanup -v` |
| 设计文档记录完整因果链与安全性论证 | `doc/design/调度器幽灵任务清理设计.html` | 已落库 |
