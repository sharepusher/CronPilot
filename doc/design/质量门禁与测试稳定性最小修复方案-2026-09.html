质量门禁与测试稳定性最小修复方案（2026-09-04）

状态：已确认（本轮） · 范围：仅修复验证链路阻断项，不做业务能力变更

1. 问题

  • tests.test_rbac_scope.TestScopeIntegration 单独运行报 rbac_registration_requests 表缺失。
  • scripts/verify_golden_path.sh 的 docs_rfc 检查固定 URL 返回 404。
  • scripts/check_css_token_reachability.py --check 对注释里的 animation: 文本误报为缺失 keyframe。
  • scripts/check_postmortem_completeness.py --check 报告 doc/postmortem/index.html 缺少对应 MD。

2. 根因

问题根因
Scope 集成测试单跑失败测试初始化对登录链路依赖的模型表导入不完整，存在隐式顺序依赖。
golden path 文档检查 404脚本内 URL 契约未跟随文档目录结构演进（deps/ 子目录）。
CSS reachability 误报静态解析未先剥离注释，注释中的示例文本被当成真实 CSS 声明。
postmortem completeness 失败postmortem 索引页存在 HTML/MD 对照遗漏，未执行一次完整文档同步闭环。

3. 方案

采用最小改动策略，逐项修复验证阻断点：

  1. 补齐测试模型导入，消除单测顺序依赖。
  2. 更新 smoke_http.sh 的 RFC 检查 URL 为真实路径。
  3. 在 reachability 脚本中先去除 CSS 注释，再解析动画引用。
  4. 执行并提交文档同步产物，补齐 doc/postmortem/index.md。

4. 范围

类型路径说明
测试tests/test_rbac_scope.py仅补导入，确保建表完整。
脚本scripts/smoke_http.sh仅修正 docs_rfc URL。
脚本scripts/check_css_token_reachability.py仅修复注释误判。
文档同步doc/postmortem/index.md由同步脚本生成。

不做：不改 RBAC 权限策略、不改 API 行为、不改任何页面交互与样式设计。
