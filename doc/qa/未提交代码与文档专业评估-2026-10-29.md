## 2. 必须处理的发现

### R1 · P1 · 原生确认回显重新签发快照，破坏并发保护

**位置：**`app/rbac/views.py:798–807, 901–918`。POST 先基于数据库当前值生成 `edit_ctx`；确认/理由失败后虽然保留提交字段，却回显这个新 token，未保留已验签的页面原始 token。

**复现：**GET 时邮箱为 old；其他请求改为 concurrent；旧页面请求清空且未确认；服务返回确认表单，其 token 的 original 已变成 concurrent；使用该表单确认提交，返回“保存成功”，邮箱变成 NULL。设计本应拒绝陈旧确认，实际将未展示的新邮箱当作已确认原值。花名等保留字段也可能在该回显过程中被重新解释为对新快照的修改。

```
original_email=old@example.invalid
reissued_original_email=concurrent@example.invalid
response.errcode=0; response.errmsg=保存成功
stored_email=null
```

**建议：**确认回显保留最初通过验签的 token 和 original；若需要切换到新基线，必须先明确展示新值并要求重新编辑确认。增加“并发修改发生在首次 POST 之前 → 原生确认回显 → 二次提交”的端到端路由测试，断言 CONFLICT、保留 concurrent 和零成功审计。现有原生回退测试只检查输入/字段数量，没有验证 token 连续性。

### R2 · P1 · MySQL 验证脚本会无条件删除传入数据库的已有表

**位置：**`scripts/verify_user_edit_transaction_mysql.py:51–55, 175–179`。任意 `--database-url` 进入 `verify()` 后立即 `db.drop_all()`，未校验后端、专用库标记、已有表或用户明确的销毁意图。导入模型的表将被删除；当前进程 metadata 更大时影响面随之扩大。误把开发或生产连接串用于验收会丢失业务数据。

**建议：**连接前验证 MySQL 和专用测试库命名，默认拒绝非空库，优先生成唯一空库并只清理本轮创建的数据。可参考 `scripts/benchmark_registration_scope.py::assert_isolated_database` 与 `ensure_empty_schema` 的拒绝式隔离思路。新增负向测试，断言非法 URL/非空库在任何 DDL 前拒绝。本轮仅静态确认危险调用链，未执行该破坏性脚本。

### R3 · P2 · 业务组选项选择器错误，既漏拦 no-op，也吞掉真实组修改

**位置：**`app/templates/redesign/user_form.html:287–306`。`[name="group_ids"]:selected` 要求选中节点自身带 name；实际 name 在 select，selected 在 option。因此多选框中的选项完全读不到，只有 locked\_group 隐藏 input 的分支可用。

```
真实 Chrome + 仓库 jquery.js：
当前选择器匹配数 = 0
select[name=group_ids] option:selected 匹配数 = 1
真实按钮点击（执行当前模板脚本 + common-redesign.js）：
unchanged_specific_group: posts=1, messages=[]
global_to_specific_group: posts=0, messages=[未检测到变更，无需保存]
```

**影响：**目标原本绑定具体业务组时，原样提交仍被前端判为变化并发送 POST；后端通常会挡为 no\_change。更严重的是目标原为全局 admin（快照 group\_ids=[]），管理员仅把“全部”改成具体组时，前端仍读出 [] 并提示无变更，直接阻止保存，权限收窄不生效。全局 actor 可编辑这种目标，因此不是不可达边界。

**建议：**正确读取 select 的 option:selected，或读取 select.val() 并归一化，同时兼容隐藏 input。浏览器测试分别覆盖单组锁定、具体组多选、全局 admin 改具体组，直接计数 POST 并核对持久化组关系；字符串包含断言不能替代执行 JS。

### R4 · P2 · 审计兼容策略与冻结设计不一致，完成声明超过证据

**位置：**`app/rbac/services.py:127–160` 与设计 **D6c**（设计 HTML 第 56 行）。D6c 明确要求未知字段/类型或形状错误整体回退，“不部分猜测渲染”；实现却把未知 changes 字段标记为 partial，继续展示已知字段，且没有校验顶层键集合。专项测试还固定了 partial 行为。这是代码/测试自洽而偏离设计，不是已发现的 XSS。

**建议：**先裁定整条回退还是部分兼容，再对齐设计、解析器、测试和 Review，不以测试通过倒推契约已满足。U3 验收“前后端规范化一致”“无 JS 回退完备”、设计 rev.2.4/索引/Release Notes 的“全部闭环”被 R1/R3 反例否定，应在修复及重验后更新状态。当前文档也未列出七种 outcome 的逐场景浏览器可重放证据，单测 PRG 不能代替完整浏览器矩阵。

## 3. 已成立的优点与合理性

- 签名快照不承担授权；写边界再次从数据库读取 actor/target、检查权限和 Scope，职责分离正确。
- 将意图差异与有效差异分开、资料独立比较、角色与组耦合比较，适合小型管理写入。R1 是回显链路丢失原值，并不否定三方比较本身。
- 业务与 JSON v1 审计同 Session/flush/commit，且授权副作用仅由有效角色/组变化触发，改善原有第二次提交导致的审计丢失。
- COMMIT\_UNKNOWN 表述保守，避免把连接确认丢失误报成明确失败；普通自动转义展示审计字段，没有引入原始 HTML 注入。
- 没有新增表、依赖或全站事务框架；成本与低并发管理场景匹配。管理员降权会锁额外 admin 行，不能将所有写入的锁成本一概称为“仅两个用户”。
- 文档双格式、索引、分批与七项复盘结构总体齐备；横向风险审计主张按入口独立设计，避免将本切片机械推广，方向合理。

## 附录：R3 浏览器复现

以下脚本执行当前模板中的实际用户编辑脚本和公共 Ajax 文件，以隔离 DOM 检查提交数。脚本未连接业务服务，也不写业务数据。

```
import json
from pathlib import Path
from playwright.sync_api import sync_playwright
root=Path('/Users/summer/projects/opensource/CronPilot')
source=(root/'app/templates/redesign/user_form.html').read_text().split('{% if user and not view_mode %}')[1].split('{% endif %}')[0]
with sync_playwright() as p:
 browser=p.chromium.launch(executable_path='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome',headless=True)
 for label,original_groups in [('unchanged_specific_group',[1]),('global_to_specific_group',[])]:
  page=browser.new_page()
  page.set_content('''<form class="js-ajax-form js-user-edit-form" novalidate action="/rbac/users/edit"><input name=email value="a@example.invalid"><input name=nickname value=old><select name=job_title><option selected>qa</option></select><select name=role><option selected>admin</option></select><select name=group_ids multiple><option value=1 selected>A</option><option value=__ALL__>ALL</option></select><button type=submit class=js-ajax-submit>保存</button></form>''')
  page.add_script_tag(path=str(root/'app/static/js/jquery.js'))
  page.evaluate('window.posts=0; window.messages=[]; window.CpToast={success:function(m){messages.push(m)}}; jQuery.ajax=function(){posts++};')
  page.add_script_tag(path=str(root/'app/static/js/common-redesign.js'))
  original=dict(email='a@example.invalid',nickname='old',job_title='qa',role='admin',group_ids=original_groups)
  page.add_script_tag(content=source.replace('{{ user_edit_original|tojson }}',json.dumps(original)))
  page.evaluate('window.posts=0;window.messages=[]')
  page.click('button')
  print(label,page.evaluate('({posts:posts,messages:messages})'))
  page.close()
 browser.close()
```
