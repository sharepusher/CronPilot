测试环境基线

  • Python：3.8～3.11（与 Flask 1.1 / Werkzeug 1.0 兼容；勿用 3.12+ 跑完整应用）
  • 配置：项目根目录 conf.ini（已在 .gitignore，勿提交）
  • 启动：bash scripts/start_local.sh 或见下文「本地启动」
  • 管理端：http://127.0.0.1:5001/ · 用户名 admin + 密码（空库种子自 login_pwd；有用户后改密走「用户管理」）
  • 自动化：python -m unittest tests.test_p0_phase_a -v（12 用例，无需 DB）

详细用例

OPT-P0-01 · SQL 参数化

TC-P0-01-01删除定时任务时关联 job_log 被清除
前置已登录；存在任务 A 且至少有 1 条执行记录
步骤任务列表 → 删除任务 A → 查看该任务执行记录列表
预期任务消失；对应 job_log 无残留；无 SQL 报错
实现JobLog.query.filter(...).delete()（job_log_service）
TC-P0-01-02日志超限清理使用 ORM
步骤将某任务执行记录增至 > job_log_counts，等待 cron_del_job_log 或手动触发
预期仅保留最近 N 条；代码中无 execute("% 拼接

OPT-P0-02 · 密码哈希

v1.0+：Web 登录校验 rbac_users；下方用例描述种子阶段 login_pwd 与哈希工具行为。日常改密见「用户管理 → 编辑 → 新密码」。

TC-P0-02-01空库：明文 login_pwd=123456 可种子并以 admin/该密码登录
TC-P0-02-02空库前执行 python scripts/hash_login_password.py 你的密码 写入 login_pwd 后，可以哈希值完成种子并以相同明文登录
TC-P0-02-03POST /check_pass（须带 username+password）正确 → 302 到 /cron_list
注意修改 login_pwd 后须重启才影响尚未种子的空库；已有用户后改 login_pwd 无效，须走用户管理改密

OPT-P0-03 · SSRF 防护

TC-P0-03-04Web 添加任务 req_url=http://127.0.0.1/x
预期JSON errcode:1，msg 含「不允许回调本机」
TC-P0-03-03url_allow_hosts=8.8.8.8 时仅允许该主机
TC-P0-03-05若绕过保存（历史数据），触发执行后 job_log 记录「安全校验未通过」

OPT-P0-04 · JSON 契约

TC-P0-04-01web_api_return(0,...) 返回 "errcode": 0（数字）
TC-P0-04-02任务列表暂停/删除等 Ajax 操作有成功提示（非静默失败）

OPT-P0-05 · 校验统一

TC-P0-05-03Web 添加 p0_ok_test 后，API 同 task_name 更新 hour → 成功
TC-P0-05-03 反例API 提交 req_url=http://127.0.0.1 → errcode:1

手工 curl 脚本（可复制）

BASE=http://127.0.0.1:5001
COOKIE=/tmp/xnc_cookie.txt

# 登录（密码与 conf.ini 一致）
curl -s -c "$COOKIE" -b "$COOKIE" -X POST "$BASE/check_pass" \
  -d "password=123456" -L -o /dev/null -w "login %{http_code}\n"

# SSRF 应失败
curl -s -b "$COOKIE" -X POST "$BASE/cron_add" \
  -d "task_name=ssrf_test" -d "hour=9" -d "minute=0" \
  -d "req_url=http://127.0.0.1/cb" -d "ds_ms=2"

# 合法添加
curl -s -b "$COOKIE" -X POST "$BASE/cron_add" \
  -d "task_name=ok_test" -d "hour=10" -d "minute=0" \
  -d "req_url=http://8.8.8.8/cb" -d "ds_ms=2"

# API
curl -s -X POST "$BASE/api/cron" \
  -d "task_name=ok_test" -d "hour=11" \
  -d "req_url=http://8.8.8.8/cb2"
