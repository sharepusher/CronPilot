# 文档同步说明（Linux 安装 / venv / Docker）

部分历史文档（`README.md`、`doc/index.md`、`非Docker部署指南.*` 等）曾属 **root** 属主，需在本机执行一次合并。

## 一键同步

```bash
cd /path/to/CronPilot
python3 scripts/sync_all_docs.py
sudo bash scripts/apply_pending_docs.sh
```

## 仍可能出现在 `doc/_pending_sync/` 的文件

`sync_all_docs.py` 在无法写入 root 属主文件时，会把**完整副本**写入此目录（如 `README.md`）。合并：

```bash
sudo bash scripts/apply_pending_docs.sh
```

合并后目录会被清空；再运行 `python3 scripts/html_docs_to_markdown.py --check`。

python3 scripts/html_docs_to_markdown.py --check
