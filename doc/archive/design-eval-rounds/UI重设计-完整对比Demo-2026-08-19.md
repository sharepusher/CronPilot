X2
任务中心 · Exception Panel 操作：文字链接 → icon-btn
高优先级

**当前**：Exception Panel 每行末尾为「查看详情 →」蓝色文字链接。  
**主表对比**：主任务表格操作列已是 `icon-btn` 风格（文档图标/三点菜单）。

X6
执行记录 · 「返回内容」列 → 「响应码」列
中优先级

**当前**：「返回内容」列显示完整 HTTP 响应体文本（如 `{"code":0,"msg":"ok",...}`），内容长，列宽大，难以快速扫描成功/失败状态。  
**Mockup 要求**：改为「响应码」列，只显示 HTTP 状态码数字（200=绿 / 4xx|5xx=红 / —=超时无响应），信噪比更高。
