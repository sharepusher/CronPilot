## 不用 gh 的发布命令

```
# 可直接粘贴到交互式 Bash；严格模式只影响子 Shell。
(
  set -euo pipefail
  cd /Users/summer/projects/opensource/CronPilot
  CRONPILOT_RELEASE_SHA=$(python3.11 -c 'import json; print(json.load(open("/private/tmp/cronpilot-v420-release-ready/cronpilot-4.2.0.tar.gz.build.json"))["source_commit"])')
  test -z "$(git status --porcelain)"
  test "$(git rev-parse HEAD)" = "$CRONPILOT_RELEASE_SHA"
  git tag -a v4.2.0 "$CRONPILOT_RELEASE_SHA" -m "CronPilot 4.2.0"
  git push origin main
  git push origin refs/tags/v4.2.0
)
# 在 GitHub 网页创建 Release，选择 v4.2.0。
# 标题 CronPilot 4.2.0；说明复制 release-notes.md；只上传下列三个附件。
# /private/tmp/cronpilot-v420-release-ready/cronpilot-4.2.0.tar.gz
# /private/tmp/cronpilot-v420-release-ready/cronpilot-4.2.0.tar.gz.sha256
# /private/tmp/cronpilot-v420-release-ready/cronpilot-4.2.0.tar.gz.build.json
```

创建入口：[GitHub New Release](https://github.com/sharepusher/CronPilot/releases/new)。已有标签时命令会失败并留在父终端，不重用或强推旧标签。
