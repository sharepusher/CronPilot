请求方式: GET,POST

参数说明：

参数 类型 是否必传 说明
access_token string 否 conf.ini配置,如果没配置，证明不验证
task_name string 是 任务名称，如果存在则修改，不存在则添加。
req_url string 是 触发 URL（到点由调度器请求的地址）
req_method string 否 请求方式：GET（默认）或 POST
req_body string 否 POST 时的 JSON 对象字符串；系统会注入 cronpilot_log_id / cronpilot_sign（不覆盖已有同名字段）
task_keyword string 是 任务说明，1～500 字（需求链接、用途、特殊情况等）
run_date string 否 执行时间，如果这个存在不为空，则任务模式就变成date模式
day string 否 天
day_of_week string 否 星期
hour string 否 小时
minute string 否 分钟
second string 否 秒

参数说明：

参数 类型 是否必传 说明
access_token string 否 conf.ini配置,如果没配置，证明不验证
task_name string 是 任务名称
status int 否 操作。0关闭1开启，如果没传或者空，系统会自动判断更改状态。比如现在状态是开启则会关闭，反之！
