1. 项目定位

CronPilot 是企业内常用的「调度中心」形态：平台负责准时触发，业务系统暴露 HTTP 接口接收回调，无需把业务代码迁入调度进程。

  • 守正：保留 HTTP GET 回调、秒级 Cron、Web/API 动态配置、集群锁。
  • 出奇：借鉴 Plombery 的可观测与工程化，但不改为进程内 Python Pipeline。
  • 与原仓库：aniu-lee/xiaoniu_cron 冻结为上游参考；本仓库承接全部改造。
