用户管理 — 业务组列显示优化设计

编号：UI-OPT-用户组显示 · 日期：2026-08-26 · 状态：待确认

一、问题

当前「用户管理」表格的「业务组」列最多显示 2 个 tag，超出部分以 +N 展示并通过浏览器原生 title 提示剩余组名。

问题：

  • 当用户属于 2+ 组时，tag 换行导致表格行高不一致
  • 列宽 140px 装 2 个 tag 后空间紧张，长组名被截断
  • 原生 title tooltip 延迟 ~700ms 且无法定制样式
  • 2 个 tag 占位仍然偏多，尤其在 1440px 视口下横向空间紧张

二、方案对比

✅ 方案 A：只显示 1 个 + CSS Tooltip（推荐）
单组用户
运维组
多组用户（悬停 +N 展开）
运维组 +2 研发组、测试组
无组用户
—

优点：行高一致；列宽可缩至 100px；即时 tooltip 无延迟
缺点：需鼠标悬停才能看完整组列表

方案 B：保留 2 个 + CSS Tooltip
多组用户（悬停 +N 展开）
运维组 研发组 +1 测试组

优点：信息密度稍高
缺点：列宽仍需 140px+；2 tag 仍可能换行

方案 C：点击弹出浮层
多组用户（点击展开面板）
运维组 +2 ▾

→ 点击弹出下拉面板显示全部组

优点：移动端友好；可展示更多信息
缺点：需要 JS；交互成本高（额外点击）；触控设备才有价值

三、推荐方案详细设计（方案 A）

3.1 模板变更

文件：app/templates/redesign/_users_rows.html

<td class="col-groups-cell">
  {% set groups = user_groups_map.get(item.id, []) %}
  {% if groups %}
    <span class="um-group-tag">{{ groups[0] }}</span>
    {% if groups|length > 1 %}
    <span class="um-group-tag um-group-more"
          data-tooltip="{{ groups[1:]|join('、') }}">+{{ groups|length - 1 }}</span>
    {% endif %}
  {% else %}—{% endif %}
</td>

3.2 CSS 变更

文件：app/static/css/redesign-pages.css（.cp-page-users 作用域内）

/* 业务组 hover tooltip */
.cp-page-users .um-group-more[data-tooltip] { position: relative; }
.cp-page-users .um-group-more[data-tooltip]:hover::after {
  content: attr(data-tooltip);
  position: absolute;
  bottom: calc(100% + 6px);
  left: 50%;
  transform: translateX(-50%);
  background: var(--cp-ink);
  color: var(--cp-surface);
  font-size: 11px;
  padding: 5px 10px;
  border-radius: 5px;
  white-space: nowrap;
  max-width: 280px;
  overflow: hidden;
  text-overflow: ellipsis;
  z-index: 100;
  pointer-events: none;
}

3.3 列宽调整

.cp-page-users .c-table .col-groups { width: 110px; }  /* 140px → 110px */

四、范围

文件变更类型描述
app/templates/redesign/_users_rows.html修改groups 循环改为 [:1]，+N tooltip 改用 data-tooltip
app/static/css/redesign-pages.css修改添加 .um-group-more[data-tooltip]:hover::after 样式

不做：

  • 不改 v1 模板（rbac/users.html）
  • 不新增 JS
  • 不改后端数据结构

五、分批

单批完成（改动 ≤10 行，2 文件）

六、验收

  1. bash scripts/cronpilot.sh restart --daemon
  2. 浏览器访问 http://127.0.0.1:5001/rbac/users
  3. 验证：单组用户 — 只显示 1 个 tag，行高正常
  4. 验证：多组用户 — 显示 1 tag + "+N"，悬停 +N 弹出 tooltip 显示完整组名
  5. 验证：无组用户 — 显示 "—"
  6. 验证：tooltip 在 1440px 视口下不超出屏幕

七、风险

  • 若组名特别长（>20 字），tooltip 的 max-width: 280px 会截断 — 可接受（已设 text-overflow: ellipsis）
  • CSS tooltip 在触控设备上无法触发 — 可接受（管理后台以桌面使用为主）
