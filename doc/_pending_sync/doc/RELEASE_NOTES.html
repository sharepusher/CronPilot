回调与 API 协议

参数 / 接口说明
cronpilot_log_id每次触发的执行 UUID
cronpilot_sign回调签名（MD5）
POST /api/cron/add_log进度回传
GET /your/callback?cronpilot_log_id=<UUID>&cronpilot_sign=<MD5>
POST /api/cron/add_log  cronpilot_log_id=<UUID>&content=...
