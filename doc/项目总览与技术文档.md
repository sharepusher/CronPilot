# 项目总览与技术文档

HTTP 定时回调调度台 · 独立演进自 xiaoniu\_cron · 文档与代码一体维护

## 1. 项目定位

**CronPilot** 是企业内常用的「调度中心」形态：平台负责**准时触发**，业务系统暴露 HTTP 接口接收回调，无需把业务代码迁入调度进程。

- **守正：**保留 HTTP GET 回调、秒级 Cron、Web/API 动态配置、集群锁。
- **出奇：**借鉴 [Plombery](Plombery深度对比分析.html) 的可观测与工程化，但不改为进程内 Python Pipeline。
- **与原仓库：**[aniu-lee/xiaoniu\_cron](https://github.com/aniu-lee/xiaoniu_cron) 冻结为上游参考；本仓库承接全部改造。

## 3. Phase A 已交付能力

| 模块 | 路径 | 说明 |
| --- | --- | --- |
| URL 安全 | `app/services/url_security.py` | SSRF / 内网 / 白名单 |
| 会话 / CSRF | `SECRET_KEY`（OPT-P0-10）· `app/security/csrf.py`（OPT-P0-11） | 生产强密钥；管理端写操作 POST + token |
| 集群互斥 | `single_task`（OPT-P0-09） | Redis `SET NX EX` + token 释放 |
| Cron 校验 | `app/services/cron_validator.py` | Web + API 共用 |
| 任务写入 | `app/services/cron_service.py` | 入库 + 注册调度 |
| 日志清理 | `app/services/job_log_service.py` | ORM 删除/裁剪 |
| 密码 | `app/auth/password.py` | 明文兼容 + pbkdf2 |
| JSON | `datas/utils/json.py` | 统一 errcode 类型 |
